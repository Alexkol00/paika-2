# Паяльная мастерская

Дружелюбная статическая страница с русской адаптацией урока Adafruit о качественной пайке. Подходит для публикации через GitHub Pages.

## Что внутри

- пять шагов с фотографиями;
- интерактивные отметки выполненных шагов и индикатор прогресса;
- увеличение фотографий в доступном диалоговом окне;
- адаптивная вёрстка для телефона, планшета и компьютера;
- локальные изображения и шрифты — внешние ресурсы для отображения страницы не нужны.

Отметки прогресса действуют только в текущем сеансе и после перезагрузки страницы сбрасываются. Сайт не отправляет и не сохраняет данные.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в его корень **всё содержимое этой папки**, включая `index.html`, `styles.css`, `src`, `images`, `fonts` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/(root)` и нажмите **Save**.

Сборка и установка зависимостей не требуются. Все пути относительные, поэтому страница работает и в пользовательском, и в проектном репозитории GitHub Pages.

## Локальный просмотр

Можно открыть `index.html` напрямую или запустить в этой папке:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

Источники текста, фотографий и шрифтов указаны в `CREDITS.md`.
